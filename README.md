
# 🧰 Mi Caja de Herramientas

Repositorio personal donde recopilo scripts, herramientas y pequeños proyectos desarrollados en diferentes lenguajes de programación.

El objetivo es tener todas mis utilidades organizadas en un único lugar, para poder consultarlas, reutilizarlas y mejorarlas cuando sea necesario.

---

# 📂 Contenido

- 🌐 HTML / CSS — Páginas web, interfaces y ejemplos de diseño.
- 🐍 Python — Scripts de automatización, utilidades y herramientas.
- ⚡ JavaScript — Funciones, scripts y herramientas web.
- 🔧 Otros lenguajes — Experimentos, pruebas y utilidades diversas.

# 🚀 Uso

1. Explora las carpetas según el lenguaje que te interese.
2. Abre el script que quieras utilizar.
3. Lee las instrucciones o comentarios incluidos en el código.
4. Ejecuta la herramienta siguiendo sus requisitos.

Algunas herramientas pueden necesitar dependencias adicionales o una configuración específica.
